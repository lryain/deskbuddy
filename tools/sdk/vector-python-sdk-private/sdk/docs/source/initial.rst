Initial Setup
#############

------------
Installation
------------

To install the SDK on your system, select the instructions for your computer's operating system.

* :ref:`install-macos`
* :ref:`install-windows`
* :ref:`install-linux`


--------------------
SDK Example Programs
--------------------

Lrya provides example programs for novice and advanced users to run with the SDK. Download the SDK example programs here:

  * :verlink:`macOS/Linux SDK Examples <lrya_vector_sdk_examples_0.0.0.tar.gz>`

  * :verlink:`Windows SDK Examples <lrya_vector_sdk_examples_0.0.0.zip>`

Once downloaded, extract the packaged files to a new directory.
